# v59：单层整帧复制实验

本次公开的是已经结束 RAM 测试的 **v59b**，不是后续版本。候选内核 SHA256：`136c6a00184f8dd2527306f6df8e4fde1d1f6f91ed3f9f7971548a7996086f88`。

## 实现原理

在 v58h 单任务在途 GPU 异步提交的基础上，减少 CPU 合成工作：只有完整单层 1125×2436 BGRA、pitch=4544、无 client alias 的表面才有资格进入快速路径。MiniIOSurface 字段来自实际编译布局，不凭推测读取。长度、溢出、重叠及像素格式均有检查。

在原 compositor_frame 的 acquire 顺序中选择 FREE 目标槽，完整覆盖时跳过上一帧保留复制；原 drawLayer 调用点以一次 memcpy 写入自有缓冲。局部、多层、其他格式及资格失败沿用原路径，失败时恢复原 latest。原 GPU ready、队列唤醒、fLock、record、表面释放和整帧发布均保留。

DPU 仍读取自有 A/B 缓冲，缩放、缓存维护、完成检查、回退和恢复链沿用前序实现。退出依次停止呈现线程、恢复 DPU、记录 FAST 统计，再等待 GPU 排空并走原有定时返回。它仍有一次 CPU 复制，不是源表面直接 DMA。

构建器只复用审计过的旧 GPU 函数内部区域，实际载荷 1577 字节，额外改三个 BL；保留原入口分支和数据区。原触控、GPU 异步和频率请求保持。v57/v58 的670MHz请求收到 ACK，但没有测量实际 GPU 时钟。

## 源码入口

- `tools/lmi-display-fast-v59.c`、`.h`：资格解码、整帧复制、回退和退出统计。
- `tools/lmi-display-direct-plan.c`、`.h`、`lmi-display-surface-abi.h`：资格与实际布局；资格模块不代表直接 DMA 已集成。
- `tools/lmi-display-compositor-v56.c`、`lmi-display-pipeline-v51.c`：保留的合成/缓冲管线。
- `tools/lmi-gpu-desktop-v58.c`、`build-lmi-gpu-async-v58.py`：一个在途 GPU 任务及完成/排空检查。
- `tools/build-lmi-display-v59.py`：精确基线、代码区域和分支检查。
- `tools/lmi_display_v59_policy.py`：祖先来源验证、候选准入和证据判定。
- `tools/check-lmi-display-fast-v59.py`、`check-lmi-display-v59-policy.py`：主机集成与日志反例检查。

## 已结束的实机结果与已知缺陷

DPU route2 记录2812桌面帧，无回退，恢复 DPU 和 GPU 退出排空通过。实际体验反馈为流畅度改善、其余功能正常，但左右滑动和上划返回桌面仍掉帧。native 时间窗存在明显长帧；静止与交互混合计数不等于动画 FPS，也不能推导受控跨版本提速。

cache clean 加受保护 kickoff 为625.03微秒/帧；不含扫描输出、合成和 GPU 绘制，不能视作整帧耗时。实验使用固定 CRC 归一化；严格像素等价和完整硬件缩放验证仍为 false。

**FAST 计数无效。** helper 以 ELF AArch64 ABI 编译，却直接调用 Darwin 内核可变参数 snprintf，整数可变参数传递方式不兼容；反汇编和实机异常数值支持该诊断。主机 Linux ASan/UBSan 测试不能覆盖这个跨 ABI 问题。policy 保持 `counts_valid=false`、`fast_path_exercised=false`，不能把体感改善归因为已证实的快速路径命中。本次原样公开 v59 的问题源码及说明，没有把后续修正版混入。

整体仍为 **INCOMPLETE**：保留原 index1 频率断言失败，另有 FAST 统计 ABI 缺陷。Android 已返回，boot/dtbo 原哈希一致。原始证据哈希及筛选摘要见 `evidence/v59-display.json`；不发布系统镜像或原始设备日志。

## 构建与检查范围

公开源码包含截至 v59 的显示管线、前序构建/准入依赖和测试器冻结快照，来源哈希记录在 `source-manifest.json`。完整候选生成依赖私下取得的 iOS/SDK/固件及前序固定构建产物；这些二进制没有分发。构建器保留原实验目录、WSL 路径和哈希守卫，不能宣称从此仓库单步即可复现完整启动镜像。路径调整后仍需满足原始哈希/ABI前置，不能直接删除守卫。

可独立执行的离线检查（Linux/WSL，Python3、Clang）：

```sh
python3 tools/check-lmi-display-fast-v59.py
python3 tools/check-lmi-display-v59-policy.py
python3 tools/check-lmi-gpu-async-v58.py
```

17个整帧集成场景使用真实冻结 v56 compositor 与 v51 pipeline；46个证据用例覆盖缺失、重复、乱序和错误计数。离线 PASS 不覆盖上述目标端可变参数 ABI，也不表示实机整体验证通过。发布过程不操作设备。
